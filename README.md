# ai-tcr

Программа принимает текстовый файл с рабочими материалами и формирует ответ с помощью локальной языковой модели.

Программа не изменяет исходный код и не отправляет ответы клиентам автоматически. Все результаты проверяются сотрудником.

## Подготовка к запуску 

- Python 3.10 или более поздней версии;
- установленная локально программа Ollama;
- загруженная в Ollama языковая модель;


##  Пример использования

Создайте файл `requirements.txt`
```
Пользователь должен иметь возможность войти в систему
по адресу электронной почты и паролю.

При неверном пароле система должна показать сообщение об ошибке.
Пароль не должен отображаться на экране в открытом виде.
```

Запустите подготовку тест-кейсов: 

```python
python ai_tcr.py \
  --mode testing \
  --input requirements.txt \
  --output test_cases.txt
```

После выполнения в файле `test_cases.txt` появится черновик тест-кейсов. Сотрудник должен проверить, например:

- предусмотрен ли успешный вход с корректными данными;
- проверяется ли сообщение при неверном пароле;
- проверяется ли скрытие вводимого пароля;
- не добавила ли модель неподтверждённые требования.

В журнал metrics.jsonl записываются режим, модель, время генерации и статус операции. Исходный текст и ответ в журнал не включаются.

## Другие команды

Анализ требований: 

```python
python ai_tcr.py \
  --mode requirements \
  --input requirements.txt \
  --output analysis.txt
```

Помощь в разработке:

```python
python ai_tcr.py \
  --mode development \
  --input task.txt \
  --output development_result.txt
```

Подготовка документации:

```python
python ai_tcr.py \
  --mode documentation \
  --input program_description.txt \
  --output documentation_draft.txt
```

Подготовка ответа поддержки:

```python
python ai_tcr.py \
  --mode support \
  --input support_materials.txt \
  --output support_reply.txt
```

Для режима поддержки в `support_materials.txt` необходимо поместить и обращение пользователя, и соответствующую выдержку из базы знаний. 

Прототип не подключается к базе знаний автоматически.
